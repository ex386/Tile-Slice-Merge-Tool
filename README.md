# 切片拼接还原（Tile Slice Merge Tool）

一个由 AI 辅助生成的纯前端图片 / 视频切片工具。可以把多张切片拼接还原，也可以将图片或视频分割成多个切片，并导出供后续还原使用的配置文件。

- **项目地址：** https://github.com/ex386/Tile-Slice-Merge-Tool
- **运行方式：** 浏览器直接打开 `index.html`
- **后端依赖：** 无
- **文件处理：** 在本地浏览器中进行，不需要将素材上传到项目服务器

## 功能概览

### 拼接还原

- 支持拖拽或选择多张图片、视频素材。
- 支持九宫格、横向、竖向排列。
- 可调整素材顺序，并在画布中查看拼接结果。
- 支持导入 ZIP / JSON 配置，按记录的位置恢复切片。
- 配置 ZIP 中的切片可进行 MD5 完整性校验。
- 图片可导出为 PNG、JPEG 或 WebP。
- 支持导出 WebM 视频和 GIF 动画。

### 分割切片

- 支持导入图片或视频。
- 支持九宫格、横切、竖切等分割方式。
- 可设置行数、列数。
- 专业模式支持自定义切割线位置，并可拖动或精确调整。
- 提供视频画面变化区域检测辅助生成切割线。
- 支持导出图片切片、视频切片、GIF 切片及配置文件。

### 配置与校验

- 配置文件记录源素材尺寸、切片位置等信息。
- 导出的配置可用于后续拼接还原。
- 支持 ZIP / JSON 配置导入。
- 对包含 MD5 信息的切片进行完整性校验；缺失或不匹配的切片可能影响还原结果。

## 快速开始

1. 从本仓库下载或克隆项目。
2. 使用现代浏览器打开根目录中的 `index.html`。
3. 根据用途选择「拼接还原」或「分割切片」。
4. 将素材拖入页面，或点击导入区域选择文件。
5. 设置排列 / 分割方式，检查画布预览。
6. 通过相应的导出按钮保存结果。

通常不需要安装依赖或启动后端服务。若浏览器限制了某些本地文件操作，可尝试使用最新版 Chrome、Edge、Firefox 或 Safari 打开。

## 常见使用场景

### 将多张图片拼成完整图片

1. 进入「拼接还原」模式。
2. 导入所有切片。
3. 选择合适的排列方式，并检查切片顺序。
4. 如顺序不正确，手动调整素材顺序。
5. 点击「保存图片」导出拼接结果。

### 将图片或视频分割成切片

1. 进入「分割切片」模式。
2. 导入需要分割的图片或视频。
3. 选择分割方式并设置行数、列数。
4. 如需精确控制切片边界，切换到专业模式调整切割线。
5. 选择所需的导出方式，并保存切片与配置。

### 使用配置文件还原

1. 在拼接还原模式中导入之前导出的 ZIP 或 JSON 配置。
2. 如果使用 ZIP，工具会尝试读取其中的配置和切片。
3. 检查还原结果及校验提示。
4. 如有缺失素材，请补充对应切片后再导出。

## 浏览器与性能说明

- 建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。
- 视频导出依赖浏览器的 `MediaRecorder` 和 `canvas.captureStream` 支持。
- 视频帧率检测使用 `requestVideoFrameCallback`；不支持该接口的浏览器可能使用回退值。
- GIF 编码和视频处理可能占用较多内存与 CPU。处理大尺寸或长视频时，建议先使用较小的输出尺寸、帧率或调色板测试。
- 不同浏览器对视频格式、编码器和导出能力的支持可能不同。
