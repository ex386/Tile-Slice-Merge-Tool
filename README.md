# 切片拼接还原 (Tile Slice & Merge Tool)

这是一个完全运行在浏览器纯前端的轻量级、无损图片与视频切片拼接/还原工具。

**💡 主要用途**：特别针对 **X (原 Twitter)** 等社交平台上被拆分长图、九宫格连图或拼接切片的情况，提供快捷的一键排序、对齐与无损缝合还原功能，让你可以轻松恢复出原汁原味的大图或视频。

---

## 🌟 核心特性

- **X (Twitter) 图片拆分缝合**：
  - 支持将从 X 保存的 2x2、3x3 九宫格、长图切片一键拖入，快速按照顺序自动对齐拼接为无损大图。
  - 画布支持拖拽调整顺序，实时预览拼接缝合效果。
- **双向处理模式**：
  - **拼接还原**：将多张图片/视频切片重构为完整的九宫格或自定义行列大图/视频。
  - **分割切片**：将单张大图或视频分割为指定行列的多个小分片（方便发布至 X 等平台）。
- **自定义与自动检测**：
  - **自定义切割线**：专业模式下支持通过鼠标拖拽或输入百分比/像素（px）值精准微调切割线位置。
  - **智能视频变动检测**：基于视频帧采样算法，自动分析视频画面中的运动/变化区域并精准绘制切割线。
- **智能配置还原 (config.json)**：
  - 分割导出时会自动生成包含图片原始尺寸、切片坐标及 **MD5 校验码** 的配置文件。
  - 支持直接导入带配置的 ZIP 包或 JSON 文件，工具将自动比对切片 MD5 并精准还原到原图位置，即使顺序打乱或缺失也能自动补全。
- **丰富多样的导出支持**：
  - **图片导出**：支持 PNG（原图无损）、JPEG、WebP 格式及缩放/质量微调。
  - **视频与 GIF 导出**：支持将合成的动态视频导出为 WebM 视频，或调整帧率（自动匹配原视频 fps）、调色板（64-256色）与宽度导出为高品质 GIF。
- **全端响应式 & 纯前端安全**：
  - 界面适配桌面端与移动端，支持侧栏收折与触控操作。
  - **所有文件处理均在本地浏览器内完成**，零数据上传，绝对保证隐私与数据安全。

## 🚀 快速开始

无需安装任何复杂的依赖环境，项目采用单文件纯前端架构。

1. **直接运行**：双击下载好的 `A.html` 文件，即可在任何现代浏览器（Chrome / Edge / Firefox / Safari）中打开使用。
2. **部署至静态服务器**：也可将 `A.html`（或重命名为 `index.html`）部署至 GitHub Pages、Vercel、Nginx 或任何静态 Web 服务器。

## 📖 使用指南

### 1. 拼接 X (Twitter) 图片 / 多图还原 (Merge Mode)
1. 将需要拼接的 X 平台图片切片**批量拖拽**至页面左侧上传区。
2. 在“排列方式”中选择 **九宫格 / 横向 / 竖向**（如 2 行 2 列，或 1 行 3 列）。
3. 如果下载时的顺序错乱，直接在主画布区**拖拽切片**自由调整图片位置。
4. 调整无缝对齐后，点击导出为无损 PNG 或 WebP 图片。

> 💡 **使用配置还原**：点击“从配置还原”导入先前分割导出的 `zip` 或 `json` 文件，拖入对应的素材图片，系统会自动进行 MD5 比对并在画布中准确定位切片。

### 2. 分割切片 (Split Mode)
1. 切换至顶部模式条的 **✂️ 分割切片** 选项卡。
2. 拖入需要分割为长图/切片以发布到 X 的原始图片或视频。
3. 选择预设模式（九宫格 / 横切 / 竖切）并指定行数列数。
4. **专业模式**功能：
   - 切换为 **自定义位置** 模式，直接在画布上拖拽黄色切割线，或在左侧列表精确修改坐标。
   - 点击 **🔍 自动检测视频变化区域**，系统会自动分析视频各区域变化并生成切割线。
5. 点击导出按钮导出打包切片与 `config.json` 的 ZIP 包。

## 🛠️ 技术实现细节

- **技术栈**：HTML5, CSS3, JavaScript (ES6+), Canvas API, Web Audio/Video API.
- **算法实现**：
  - **手写 MD5 算法**：实现高效快速的二进制 ArrayBuffer 散列计算，用于分块特征比对。
  - **纯 JavaScript 无依赖 ZIP 打包与解包**：基于 Store 存储格式与 CRC32 校验手写 ZIP 文件生成器与解析器。
  - **视频帧率检测**：利用 `requestVideoFrameCallback` 实时分析视频源帧率，自动适配 GIF 帧率导出。
  - **递归切割算法**：自定义矩形递归切分 logic，支持任意横竖线交错分割。
