# 切片拼接还原 (Slice Merger)

一个纯前端、由 AI 生成的图片/视频切片工具，用于将分割后的图片或视频重新拼合还原。特别适用于拼合在 X（原 Twitter）等平台上被分割上传的图片。

## 项目简介

在 X 等社交平台上，长图或高清图片有时会被自动分割成多张图片上传。本项目提供了一套完整的拆分与还原解决方案：

- **分割切片**：将一张长图或视频按九宫格、横切、竖切等方式分割成多个切片，并生成包含 MD5 校验的配置文件。
- **拼接还原**：将切片素材按顺序拼合回原图，或导入配置 ZIP/JSON 自动还原到原始位置。

所有处理均在浏览器本地完成，无需上传文件到服务器，保护隐私且速度快。

## 主要功能

### 拼接还原（Merge）
- 拖拽导入多张图片或视频切片
- 支持九宫格、横向、竖向三种排列方式
- 手动拖拽调整切片顺序
- 支持从配置 ZIP / JSON 导入，自动匹配切片位置并校验 MD5
- 导出为 PNG / JPEG / WebP 图片
- 导出为 WebM 视频或 GIF 动画

### 分割切片（Split）
- 导入单张图片或视频进行分割
- 九宫格、横切、竖切三种分割方式
- 均分或自定义切割线（支持拖动调整、px/% 精确输入）
- 自动检测视频变化区域并生成切割线
- 导出图片切片 + 配置 ZIP（含 MD5）
- 导出视频切片 + 配置 ZIP
- 导出 GIF 切片 ZIP
- 仅导出配置 JSON

### 配置与校验
- 配置文件中包含源尺寸、切割线位置、切片位置及 MD5 哈希
- 导入配置时自动校验切片完整性
- 缺失切片会以红色虚线框标出

## 使用方法

### 拼合 X 上的图片

1. 打开 `index.html`（无需服务器，直接双击即可）
2. 默认处于「拼接还原」模式
3. 将 X 上保存的多张切片图片拖入左侧区域
4. 按文件名自然排序（工具会自动排序）
5. 根据需要选择「九宫格 / 横向 / 竖向」排列方式
6. 点击「保存图片」导出拼合后的完整图片

> 提示：如果切片顺序不正确，可在左侧列表中手动上移/下移，或直接在画布上拖动切片调整位置。

### 分割图片或视频

1. 切换到「✂️ 分割切片」模式
2. 拖入一张图片或视频
3. 选择分割方式（九宫格/横切/竖切）和行数/列数
4. 专业模式下可自定义切割线位置，或点击「自动检测视频变化区域」
5. 点击「导出图片切片 + 配置 (ZIP)」生成切片包

### 从配置还原

1. 在拼接模式下点击「导入配置 ZIP / JSON」
2. 选择之前导出的配置 ZIP（包含切片）或 JSON
3. 工具会自动加载切片并按原始位置拼合
4. 缺失的分片会以红色虚线框标出，可手动拖入补充

## 技术特点

- **纯前端实现**：HTML + CSS + JavaScript，无后端依赖
- **本地处理**：所有文件处理均在浏览器内完成
- **MD5 校验**：使用纯 JS 实现 MD5 算法，校验切片完整性
- **ZIP 打包/解析**：内置 ZIP 构建与解析（Store 模式）
- **GIF 编码器**：内置基于中位切分量化与 LZW 编码的 GIF 生成器
- **视频帧率检测**：使用 `requestVideoFrameCallback` 自动检测视频帧率
- **自适应布局**：桌面端侧栏 + 画布，移动端底部抽屉式面板

## 浏览器兼容性

建议使用最新版 Chrome、Edge、Firefox 或 Safari。

- 视频导出依赖 `MediaRecorder` 和 `canvas.captureStream`
- 视频帧率检测依赖 `requestVideoFrameCallback`（不支持时回退到 30fps）
- GIF 导出在低性能设备上可能较慢，建议降低帧率或宽度
